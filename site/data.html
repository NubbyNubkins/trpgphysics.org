Data & code

Every number on this site comes from a script you can run yourself.

The scripts need Python 3 with NumPy and SciPy; some also use SymPy, the workbook builders use pandas and openpyxl, and the mass-table script also uses the periodictable package for the measured nuclear masses. Download the archive, unpack it, and run python run_all.py to reproduce every number. A description of each script, with its full source, is on the Source code page. The complete set, including every later test with its saved output, is in the public repository: github.com/NubbyNubkins/TRPG-Unified-Framework.
